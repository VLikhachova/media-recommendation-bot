# Personal Media Recommendation Bot

Готовый Telegram-бот для сохранения рекомендаций из Threads, Instagram, Pinterest и обычного текста.

## Что умеет MVP

- Принимать ссылки на посты и пытаться извлечь публичные Open Graph title/description.
- Принимать скопированный текст публикации.
- Принимать скриншоты и распознавать названия через vision-модель.
- Извлекать названия с помощью OpenAI и раскладывать по категориям.
- Сохранять рекомендации в локальную SQLite-базу.
- Пропускать дубликаты в пределах одной категории.
- Показывать списки, искать, выбирать случайную непросмотренную рекомендацию.
- Отмечать просмотренное и удалять записи.

Основные категории: фильмы, сериалы, книги и разное. Дополнительные списки можно включать, скрывать и переименовывать через `/categories`.

## Важно про Instagram / Threads

Автоматическое чтение ссылок не гарантируется: платформы часто блокируют серверные запросы или не включают текст поста в публичные метаданные. Если ссылка не читается, бот попросит прислать текст подписи или скриншот. Это ожидаемое ограничение, а не ошибка базы или Telegram.

## Требования

- Node.js 22+
- Google Chrome installed locally (needed to load all images in public Threads carousels)
- Telegram Bot Token от @BotFather
- OpenAI API key с доступом к выбранной модели
- `TMDB_API_TOKEN` — необязательный токен для карточек фильмов и сериалов

## Запуск локально

1. Распакуй архив и открой папку проекта в терминале.
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Скопируй `.env.example` в `.env`.
4. Заполни `TELEGRAM_BOT_TOKEN`, `TELEGRAM_USER_ID` и `OPENAI_API_KEY`. Свой числовой Telegram ID можно узнать у @userinfobot.
5. Чтобы включить описания, создай аккаунт TMDB, получи API Read Access Token в [настройках API](https://www.themoviedb.org/settings/api) и добавь его в `.env` как `TMDB_API_TOKEN`. Сам токен никому не отправляй.
6. Запусти:

   ```bash
   npm run dev
   ```

7. Открой своего бота в Telegram и отправь `/start`.

## Развёртывание на Railway

В проект добавлен Dockerfile с Node.js 22 и Chromium, который нужен для загрузки изображений из каруселей Threads.

1. Создай приватный репозиторий GitHub и загрузи в него файлы проекта. Не загружай `.env` и папку `data`.
2. В Railway создай проект через Deploy from GitHub Repo и подключи репозиторий.
3. Создай для сервиса публичный Railway-домен и добавь переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_USER_ID`, `OPENAI_API_KEY` и, если используешь описания, `TMDB_API_TOKEN`.
4. Добавь сервису Volume с путём монтирования `/app/data`. SQLite-база должна находиться в этом каталоге, иначе данные пропадут при пересоздании контейнера.
5. Чтобы сохранить локальные рекомендации, отправь боту в личном чате файл `recommendation-backup.json`. Импорт доступен только владельцу бота, только в пустую базу и выполняется один раз.
6. Проверь, что Serverless включён в настройках сервиса, и запусти его. На Free сервисы работают в serverless-режиме. При наличии `RAILWAY_PUBLIC_DOMAIN` бот автоматически запустится в режиме webhook и зарегистрирует адрес в Telegram.

На Railway бот принимает обновления через webhook вместо постоянного long polling, поэтому сервис может засыпать между запросами. Railway обычно усыпляет его через 5–10 минут после последнего исходящего сетевого запроса и запускает при следующем входящем запросе. Первый ответ после сна может прийти с небольшой задержкой. Локальный запуск без `RAILWAY_PUBLIC_DOMAIN` продолжает использовать polling.

После проверки серверной версии останови локальный процесс, чтобы не переключать Telegram-бота обратно на polling.

## Команды

- `/start` — запуск и справка
- `/help` — помощь
- `/list` — меню категорий
- `/categories` — добавить, переименовать, скрыть или вернуть категорию
- `/movies` — фильмы
- `/series` — сериалы
- `/books` — книги
- `/games` — игры
- `/music` — музыка
- `/places` — места
- `/search слово` — поиск
- `/random` — случайная непросмотренная рекомендация
- `/done сериал 2` — отметить просмотренной запись №2 из списка сериалов
- `/type фильм 2 сериал` — перенести запись №2 из фильмов в сериалы
- `/delete фильм 2` — удалить запись №2 из списка фильмов
- В списках фильмов, сериалов и «Просмотренного» нажми кнопку с названием, чтобы открыть карточку из TMDB. Книги, аниме и остальные категории отображаются обычным списком.
- Ссылки на источники извлекаются из текста поста и привязываются к соответствующим рекомендациям; ссылки навигации и профилей Threads не добавляются.
- `/credits` — источник данных и атрибуция TMDB

Нумерация отдельная в каждом списке: самая старая рекомендация всегда №1. После удаления или переноса номера автоматически сдвигаются.

Основные категории — фильмы, сериалы, книги и «Разное». Отдельный встроенный список «Просмотренное» хранит завершённые фильмы и сериалы. В меню `/categories` можно добавить собственную категорию, переименовать любую или скрыть дополнительную. Скрытие не удаляет список и его рекомендации; их можно вернуть в меню. Распознавание новых рекомендаций использует активные категории, кроме списка «Просмотренное».

Чтобы переместить фильм или сериал в «Просмотренное», напиши, например, «посмотрела Керри» или «добавь Керри в просмотренное». Если найдено несколько совпадений, бот предложит выбрать нужную запись. Перенос сохраняет исходные ссылки и заметки.

## Безопасность

- Не публикуй `.env` и не отправляй токены в чат.
- Не добавляй `.env` в Git.
- Бот принимает команды только от Telegram ID, указанного в `TELEGRAM_USER_ID`.
- База хранится в `data/recommendations.sqlite`. Для постоянной работы на сервере нужен постоянный диск/volume и резервные копии.

## Ограничения первой версии

- Результаты AI нужно проверять: возможны ошибки распознавания названий и категорий.
- Каталоги могут не найти произведение, если его локализованное название отсутствует среди вариантов поиска.
- Списки пока доступны командами Telegram, веб-интерфейса нет.
- Для постоянной работы бот должен быть развёрнут на сервере; локальный запуск работает, пока запущен процесс.


## Приглашения и личные библиотеки

Бот поддерживает до 10 активных пользователей и ожидающих приглашений вместе с владельцем. Владелец управляет доступом в личном чате:

- `/invite @username` — зарезервировать место для пользователя;
- приглашённый открывает бота и отправляет `/start`, чтобы принять приглашение;
- `/users` — посмотреть активные доступы и приглашения;
- `/revoke @username` — отозвать доступ или отменить приглашение.

Для каждого Telegram аккаунта создаётся отдельная SQLite база в `data/users`. Существующая база владельца остаётся в `data/recommendations.sqlite`. Все операции с библиотекой доступны только в личном чате с ботом; в группах бот не показывает данные. Отзыв доступа блокирует пользователя, но не удаляет его отдельную базу.
